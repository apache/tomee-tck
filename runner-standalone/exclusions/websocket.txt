# The 3 errors are one behavioral difference in a single class. The
# server-side configurator reports the extensions the client requested and
# the extensions it negotiated. TomEE's client-side WebSocket container
# (Tomcat's tomcat-websocket) always advertises its built-in
# permessage-deflate extension in the opening handshake, so that extension
# appears in the requested and negotiated lists the configurator observes,
# while the test expects only the extensions it declared. The failure
# reproduces when the class is run on its own, so it is a genuine
# Tomcat/TomEE client-container behavior to triage upstream, not a harness
# artifact.

# each client probe still runs. See runner-standalone/websocket for the
